# Spam Detection Using Machine Learning

## Project Overview
This project focuses on detecting whether a text message is Spam or Not Spam using Machine Learning techniques.

The goal is to classify messages automatically and understand how Machine Learning can be used for text classification.

## Objectives
- Understand the Spam Detection problem.
- Load and explore the dataset.
- Perform text preprocessing.
- Convert text into numerical features.
- Train a Machine Learning model.
- Evaluate model performance.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Data Collection
2. Data Loading

7. Model Evaluation
